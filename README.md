# 🍔 Food Ordering Web Application

A full-stack food ordering platform built using the **MERN Stack** (MongoDB, Express.js, React.js, Node.js). This application allows users to browse restaurants, add items to their cart, place orders, and pay via Stripe or Cash on Delivery (COD). Admins and store owners have access to role-specific features like managing orders and viewing customer feedback.

## 🚀 Features

- 👤 User authentication (signup/login)
- 🔐 Role-based access (Admin, Customer)
- 🛒 Add to cart, checkout, and place orders
- 💳 Stripe & Cash on Delivery (COD) payment integration
- 📧 Order confirmation emails via Nodemailer + Brevo (Sendinblue SMTP)
- ⭐ Store rating and reviews system
- ⚙️ Admin dashboard to manage users and stores
- 📱 Responsive UI built with  CSS

## 🛠 Tech Stack

**Frontend:**
- React.js
- CSS
- Axios

**Backend:**
- Node.js
- Express.js
- MongoDB with Mongoose
- Stripe API
- Nodemailer + Brevo SMTP
